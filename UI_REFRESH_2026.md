# CareMesh UI Refresh 2026

This release keeps the production Supabase/Auth/Gemini/reporting stack intact and applies a full visual refresh.

## Visual changes
- Aurora-style blue / indigo / teal healthcare theme
- More expressive card surfaces and gradients
- Layered glass navigation rail
- Animated page entrance and subtle hover motion
- Modern KPI cards and improved hierarchy
- Refined buttons, badges, tables, profile cards and quick links
- Modernized authentication page styling
- Responsive mobile bottom navigation + side drawer
- Better touch targets and safe-area spacing
- Reduced-motion support

## Functional UI change
The admin dashboard greeting now changes dynamically based on the user's current local time:
- Good morning
- Good afternoon
- Good evening
- Good night

No database migration is required for this UI refresh.
